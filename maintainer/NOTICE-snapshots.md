# Notice: documentation snapshots

The files in `maintainer/snapshots/` are verbatim, whitespace-normalised copies (each prefixed with one added claudit header line) of pages from
Anthropic's Claude Code documentation. The exact source URL of each copy is in the header
line of its file.

That documentation is copyright Anthropic PBC, all rights reserved. Its legal-and-compliance
page (https://code.claude.com/docs/en/legal-and-compliance.md) carries this footer, as checked
by the maintainer on 2026-10-16: "© Anthropic PBC. All rights reserved. Use is subject to
applicable Anthropic Terms of Service." The copies are not covered by this repository's MIT
licence, and no licence to them is granted here.

They are stored only so that Claudit's doc-drift tooling can detect and show changes to the
pages that Claudit's guidance depends on. Diff excerpts (the old and new text of changed
sections) can appear in this repository's doc-drift issues.

This repository is not endorsed by, or affiliated with, Anthropic.

Removal on request: anyone, including the rights holder, can open an issue on this repository
and the snapshot files will be removed from the current tree of the repository. Git history is
not rewritten unless the rights holder asks for that and the maintainer agrees.
